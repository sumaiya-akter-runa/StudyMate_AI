# StudyMate AI

StudyMate AI is an AI-powered study assistant designed to help students understand concepts, get answers to academic questions, and make learning easier through an interactive chat interface. Built with Flutter for the frontend and Django for the backend, using Docker for backend services and Groq API for AI-powered responses.

## Technology

- Flutter
- Dart
- Django
- Docker
- Groq API

## Installation

1. Open the GitHub Releases page.
2. Download `app-release.apk` from the latest release.
3. Open the downloaded APK on your Android phone.
4. Allow installation from this source if prompted.
5. Install and launch StudyMate AI.
