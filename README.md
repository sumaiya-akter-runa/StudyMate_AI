# StudyMate AI

StudyMate AI is an AI-powered study assistant built with Flutter to help students understand academic concepts through an interactive chat experience.

## Technology

- Flutter
- Dart
- Django
- Docker
- Groq API

## Download APK

Download the Android APK from the [GitHub Releases](https://github.com/sumaiya-akter-runa/studymate-ai/releases) page.

## Installation

1. Open the GitHub Releases page.
2. Download `app-release.apk` from the latest release.
3. Open the downloaded APK on your Android phone.
4. Allow installation from this source if prompted.
5. Install and launch StudyMate AI.
